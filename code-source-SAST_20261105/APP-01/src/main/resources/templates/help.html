À propos de Hélios Banque

Hélios Banque est un établissement fictif de démonstration. Toutes les données (comptes, bénéficiaires, relevés, virements) sont 100 % fictives et servent exclusivement à un environnement de test interne.

Questions fréquentes

  • Comment ajouter un bénéficiaire ? Depuis la page Bénéficiaires.
  • Comment initier un virement ? Depuis la page Virements (code OTP de laboratoire requis).
  • Où consulter mes relevés ? Sur la page Relevés.
  • Comment mettre à jour mon profil ? Depuis la page Profil.
